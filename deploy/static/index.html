Dhaka Kacchi Review Intelligence

Paste a restaurant review to see the aspect-level sentiment breakdown.

An aspect-based sentiment analysis pipeline built around Dhaka Kacchi, a Berlin cloud kitchen — fine-tuned DistilBERT trained on weak-labeled Yelp reviews, refined with a small set of hand-labeled gold examples. Predictions below ~65% confidence are shown as uncertain rather than asserted outright.

Full write-up, code, and methodology: github.com/shadmanArko/dhaka-kacchi-review-intelligence
